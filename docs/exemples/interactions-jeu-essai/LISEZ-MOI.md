# Jeu d'essai — DONNÉES FICTIVES

Ces fichiers ne contiennent **aucune information clinique**. Les couples et les
textes de risque sont des exemples destinés à vérifier que la chaîne de
chargement, de croisement et d'affichage fonctionne.

Le nom du référentiel déclaré dans `meta.json` est
« JEU D'ESSAI FICTIF — ne pas utiliser en officine ». Ce nom s'affiche tel quel
sur chaque alerte produite : impossible de le confondre avec une source réelle.

Pour charger un vrai référentiel, voir [`docs/INTERACTIONS.md`](../../INTERACTIONS.md).
